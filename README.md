# Nadin Marketplace — Future Finds

Website marketplace fashion bergaya dark futuristic neon, dipadukan layout minimalis premium.

## Fitur
- 60 produk demo dari puluhan brand
- Kategori sneakers, apparel, accessories, dan bags
- Search produk/brand, filter kategori, filter brand, sorting harga/nama
- Quick view, pilihan ukuran demo, favorites
- Keranjang interaktif tersimpan di localStorage
- Demo checkout (tidak memproses pembayaran sungguhan)
- Newsletter demo, responsive desktop/mobile, favicon

## Jalankan lokal
Buka `index.html` di browser. Koneksi internet diperlukan untuk Google Fonts dan foto Unsplash.

## Upload ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload semua file dan folder dalam ZIP ini (jangan upload ZIP-nya saja).
3. Buka **Settings → Pages**.
4. Pada Build and deployment pilih **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Simpan dan tunggu website terbit.

Foto dan font dimuat dari layanan eksternal. Harga, checkout, dan newsletter adalah demo; bukan toko aktif.
